# FácilTrazo · Dibujo 2D

Aplicación de dibujo técnico 2D compatible con DWG/DXF de AutoCAD. Corre completa en el navegador
y se puede instalar como aplicación (Edge/Chrome → Instalar FácilTrazo).

- `index.html` — la aplicación completa (un solo archivo).
- `manifest.webmanifest`, `sw.js`, `icons/` — instalación, ícono y funcionamiento sin internet.

Los dibujos nunca salen del computador: la página no envía datos a ningún servidor.
